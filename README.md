# folder-encrypt

把一个文件夹拖到程序图标上，它就用文件夹名开头的 8 位日期当密码，压成一个连文件名一起加密的 7z 包。

Windows 10/11 64 位，单个 exe，不用装 Python，也不用装 WinRAR。下载见 Releases。

## 使用场景

发资料不想被人随便看到。评审资料、投标文件、报名表、工资表、试验数据，都是压成包加个密码再发出去。

密码不用另记。这类文件夹本来就按日期起名，比如 20260812会议评审资料，密码就是 20260812。

有些时候光加密内容不够。文件名不加密的话，不输密码也能看到包里有哪些文件，光看名字就能猜出内容，比如一份写着人名的工资表。这种就得连文件清单一并加密。

## 问题解决方案

内置 AES-256，文件内容和文件清单一起加密。不输密码，连包里有哪些文件名都看不到。

压缩先写临时文件，全部压完才替换正式文件，中途失败也不会把原来的包弄丢。

哪个文件读不出来就跳过，其余照常压，最后把跳过的列出来。

## 使用注意事项

1. 文件夹名必须以 8 位日期开头，密码就是这 8 位数字。名字不对，或者拖进来的不是文件夹，程序会提示并停下。

2. 压缩包生成在这个文件夹的上一级目录，和文件夹同名，后缀是 .7z。有同名文件就直接覆盖。

3. 密码就是压缩包文件名的前 8 位，拿到包的人也就知道密码了。它防的是发错人、传错群，不防有心人。真要保密，把包改成跟文件夹无关的名字再发。

4. 对方用 7-Zip、WinRAR、Bandizip 都能打开。Windows 自带的解压不认，会报错，发之前说一声。

5. 原文件夹不删也不动，只是旁边多出一个 .7z。

6. 双击到真正开始压之间要等 1 秒左右，文件夹小的时候比较明显。

7. exe 没做签名，可能被杀软拦一下，加白名单就行。
